01 — Foundations

Design Philosophy

Notion AI's core idea is the invisible interface — the tool disappears so nothing competes with the content. Target users are knowledge workers doing focused cognitive work. The visual tone is monochrome-first: color is spent only on meaning, never decoration.

Personality
Quiet, precise, unhurried
Density
Low by default, expandable on demand
Character
Minimalist shell, maximalist depth
Reusable rule
Hide power behind restraint

03 — Foundations

Visual Hierarchy

Built almost entirely through size and weight, not color — so when color does appear, it reads instantly as meaningful.

10 — Components

Interaction Design

Hover fills are near-instant with no movement. AI generation is shown as literal streaming text at the cursor — the content is the progress indicator, no spinner needed. Transitions stay short: 120–180ms, ease-out.

11 — Components

Iconography

Line icons, 1.5–2px stroke, rounded joins. Inherit text color rather than carrying their own fixed color.

Recommended library for implementation: Lucide — closest match to this stroke-based, quiet style.

16 — System

Accessibility

Contrast
Primary text comfortably exceeds WCAG AA; double-check muted-gray combinations
Focus states
2px outline ring, offset from the element's own border
Touch targets
44px minimum on kidSpark's mobile parent views (consumer app, not desktop-first)
Screen readers
Icon-only buttons need explicit aria-labels
17 — System

Implementation Guidance

Map the token table into tailwind.config.js so every component pulls from one source of truth. CSS Grid for the outer shell, Flexbox within components — mobile-first breakpoints, sidebar as a drawer under 768px.

20 — Summary

Adapted for kidSpark

kidSpark runs two design languages under one brand — not a clone of Notion's neutral skin everywhere.

Marketing site & kid app
Warm, playful, spark-themed. Fredoka display type, gold accent, night-sky visual language. Delight-driven.
Parent dashboard
Calm, restrained, Notion-inspired. Inter throughout, borders over shadows, one accent reserved for meaning. Get in, see status, leave.
Notion AI principlekidSpark adaptation
Hide power behind restraintDashboard default view stays sparse; detail lives one click deeper
Shadow reserved for floating elementsKept literally — consistent with how spark-glow is already used meaningfully
One accent reserved for meaningSpark-gold stays the only "achievement" signal — never decorative
Inline AI trigger, not a chat bubbleWeekly summary streams into the dashboard card itself
Sidebar mirrors IA exactlyDashboard → Children → Library → Reports → Settings
