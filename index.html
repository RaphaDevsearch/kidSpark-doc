01 — Foundations

Design Philosophy

kidSpark's philosophy is playful clarity: warm and energetic enough that a five-year-old wants to open it, organized enough that nothing gets in the way of finishing a lesson. Target users are kids ages 5–10 and the parents managing their accounts. The visual tone is bright and rounded — but never chaotic. Every screen has exactly one clear next step.

Personality
Warm, encouraging, a little mischievous
Density
Low — one big idea per screen
Character
Candy-bright palette, generous whitespace
Reusable rule
One primary color per screen, one clear action

10 — Components

Interaction Design

Hover and tap states respond immediately with warmth — a soft color pop, never a jarring flash. Success moments (finishing a lesson) get a small celebratory animation, a burst of spark particles, while everyday navigation stays calm so the celebration keeps its meaning. Transitions stay short: 120–200ms, ease-out.

11 — Components

Iconography

Rounded, friendly line icons, 1.75–2px stroke. Filled where an icon represents a subject or reward, outlined where it's purely navigational — so a parent scanning quickly can tell "this is an action" from "this is decoration."

16–20px
colored when active
filled = reward
outlined = navigation

Recommended library for implementation: Lucide — a rounded, stroke-based base set that colors and fills easily to match this style.

20 — Summary

Two Contexts, One System

kidSpark uses one palette everywhere — what changes between kid mode and the parent dashboard is density and volume, not color.

Kid mode
Full-bleed color per subject, big glowing rewards, minimal text, audio-first. The palette at maximum volume.
Parent dashboard
Same palette, quieter application — white cards on a cream background, one accent used sparingly, more text density for quick scanning.
PrincipleHow it shows up
Color volumeKid mode: full-color backgrounds per subject. Parent dashboard: one accent on white cards
CelebrationKid mode: spark burst + sound. Parent dashboard: a small green checkmark
Touch targetsKid mode: 56px+. Parent dashboard: 44px
TypographyKid mode: Fredoka everywhere. Parent dashboard: Fredoka for headers, Inter for body/data
